# Grok side

Two files:

- **`system-prompt.md`** is the everyday instructions. Put it in a Grok project / custom
  instructions / bot template. It makes Grok act as the coordinator: write tasks, check results,
  report back, and never send or merge anything without you.
- **`setup-skill.md`** is a one-time guided setup. Paste it into a fresh Grok chat. Grok asks
  you questions, then builds *your* routing rules and walks you through installing the runner.

Customize first. The defaults in this repo are only examples.
